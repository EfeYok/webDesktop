## 🖥️ Nedir?

**webDesktop**, klasik bir işletim sistemi masaüstünü tamamen web teknolojileriyle (HTML, CSS, JavaScript) yeniden yorumlayan bir projedir. Hiçbir framework, hiçbir bağımlılık yok — saf, yerinde çalışan web kodu.

Açtığınız anda görecekleriniz gerçek bir masaüstü gibi hissettirir: görev çubuğu, simgeler, klasörler, sağ tık menüsü... ama bunların hepsi tarayıcınızın içinde çalışıyor.

---

## ✨ Özellikler

### 🗂️ Simge & Klasör Yönetimi
- Masaüstüne uygulama simgesi veya klasör ekleyebilirsiniz
- Simgeler; isim, URL, renk ve ikonla özelleştirilebilir
- Klasörler tıklandığında içindeki simgeleri gösteren bir popup açılır
- **Düzenleme Modu** ile simgeleri yeniden düzenleyebilir veya silebilirsiniz

### 📌 Görev Çubuğu (Taskbar)
- Alt kısımdaki görev çubuğunda **Dock** alanı bulunur
- Sık kullandığınız uygulamaları dock'a sabitleyebilirsiniz
- Sağ köşede gerçek zamanlı **saat ve tarih** gösterilir

### 🪟 Başlat Menüsü
- Windows tarzı bir başlat menüsü
- Eklediğiniz uygulamaları buradan da açabilirsiniz
- Duvar kağıdı değiştirme ve simge ekleme kısayolları

### 🖼️ Duvar Kağıdı
- Hazır duvar kağıtları arasından seçim yapabilirsiniz
- Sağ tık menüsünden veya başlat menüsünden erişilebilir

### 🖱️ Sağ Tık Menüsü
- Masaüstüne sağ tıklayarak hızlıca yeni simge/klasör ekleme
- Duvar kağıdı değiştirme ve düzenleme moduna geçiş

### 📝 Notepad
- Yerleşik basit bir metin düzenleyici (`notepad.html`)

## 🚀 Kurulum & Kullanım

Bu proje hiçbir derleme adımı veya bağımlılık gerektirmez.

```bash
# Repoyu klonla
git clone https://github.com/EfeYok/webDesktop.git

# Klasöre gir
cd webDesktop

# index.html dosyasını tarayıcıda aç
# (ya da bir local server üzerinden çalıştır)
# (yani internete ihtiyaç duymaz)
```

Alternatif olarak doğrudan canlı siteye gidebilirsiniz: [web-desktop-theta.vercel.app](https://web-desktop-theta.vercel.app)

---

## 🗃️ Dosya Yapısı

```
webDesktop/
├── index.html       # Ana masaüstü arayüzü
├── notepad.html     # Yerleşik metin düzenleyici (daha güncellemeler eklenecek)
├── script.js        # Tüm masaüstü mantığı (simge, klasör, dock, menü...)
└── style.css        # Arayüz stilleri (taskbar, modal, context menu...)
```

## 🛠️ Teknolojiler

| Teknoloji | Kullanım Amacı |
|-----------|----------------|
| **HTML5** | Sayfa yapısı; masaüstü, taskbar, modal ve menü elemanları |
| **CSS3** | Stil, animasyonlar, responsive düzen, CSS değişkenleri |
| **Vanilla JS** | Simge yönetimi, sürükle-bırak, localStorage kalıcılığı, saat/tarih |
| **Google Fonts** | DM Sans tipografisi |
| **Vercel** | Deploy & hosting |

> Herhangi bir npm paketi, framework veya build tool kullanılmamıştır.
